## Lancement du jeu

Pour lancer le jeu, se placer dans le répertoire gradius, source du projet, utiliser les commandes make compile (ou make) puis make run. make clean peut être utiliser pour nettoyer les fichiers compilé. 
S'il y a une erreur au niveau du parser, il faut mettre le dossier *PARSER* en dossier source. 

Une fois le Main.java lancé, une fenêtre s'ouvre. Il est conseillé de ne pas l'agrandir pour éviter des bugs d'affichages.
Une fois la fenêtre ouverte, un écran d'acceuil apparait. Il est indiqué les instructions :
- Appuyez sur la touche ESPACE pour lancer le jeu normalement
- Appuyez sur la touche D pour lancer le jeu en mode Debug
- C pour les crédits 

Une fois la partie terminé, il est possible de relancer le jeu sans quitter. 
Pour quitter le jeu, il faut arrêter l’exécution du code ou appuyer sur la croix de la fenêtre.
